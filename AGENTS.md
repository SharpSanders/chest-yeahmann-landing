# Creator Landing Page Template

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Framer Motion

## Project Type

Streamer and content creator landing pages.

## Design Rules

- Mobile-first
- Responsive
- Dark gaming aesthetic
- Clean modern UI
- Accessibility focused

## Structure

/components/sections
/components/ui
/lib
/data

## Rules

- Build one section at a time
- Create reusable components
- Do not modify unrelated files
- Use TypeScript properly
- Use semantic HTML

## Validation

Run:

npm run build
npm run lint

after every completed section.
